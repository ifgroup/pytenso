Contributing

Contributions to TENSO are welcome. Please open an issue first to discuss your proposed change before submitting a pull request — this helps avoid duplicate work and ensures the contribution fits the project roadmap.

All contributions should include appropriate tests and documentation updates. The source code is available at https://github.com/ifgroup/pytenso.
