Output File Configuration

Each propagation run writes its reduced density matrix to a .dat.log file. The frame_method parameter passed to spin_boson() selects the tensor network topology and also serves as the output filename prefix:

`frame_method`TopologyOutput file
`'train'`Linear chain (MPS/TT)`train.dat.log`
`'tree2'`Binary tree (TTN)`tree2.dat.log`
out_tree = 'tree2' #Output directory

outs = {
    'tree2': out_tree,

Bath Correlation Function (BCF)

The bath enters the HEOM through the bath correlation function (BCF):

$$ C(t) = \mathrm{Tr}_B\!\left[\tilde{X}_B(t)\,\tilde{X}_B(0)\,\rho_B^{\mathrm{eq}}\right] = \int_{-\infty}^{\infty}\mathcal{J}(\omega)\bigl(1 - e^{-\beta\omega}\bigr)^{-1}e^{-i\omega t}\,\mathrm{d}\omega. $$

TENSO decomposes $C(t)$ into a sum of complex exponentials via the (N−1)/N Padé scheme,

$$ C(t) = \sum_{k=1}^{K} c_k e^{ \gamma_k t}\quad \mathrm{and} \quad C^*(t) = \sum_{k=1}^{K} \bar{c_k} e^{ \gamma_k t} $$

enabling exact HEOM propagation. The bath parameters used here are:

ParameterSymbolValueUnits
DL reorganization energy$\lambda$540cm⁻¹
DL cutoff frequency$\omega_c$70cm⁻¹
BO central frequency$\Omega_b$1243cm⁻¹
BO reorganization energy$\lambda_b$161.6cm⁻¹
BO damping width$\gamma_b$10cm⁻¹
Temperature$T$300K
bath_simulation = gen_bcf(
    re_d=[540],    #Reorganization energy in cm-1
    width_d=[70],  #Width of the DL spectral density in cm-1
    freq_b=[1243], # Central Frequency of the Brownian Spectral density in cm-1
    re_b=[161.6], #Reorganization energy of the Brownian Spectral density in cm-1
    width_b=[10],  #Width of the spectral density in cm-1
    temperature=300, #Temperature in Kelvin
    decomposition_method='Pade', #Decomposition method for the bath correlation function
    n_ltc=1, #Number of low-temperature correction terms
)

System Hamiltonian and Initial State

The Hamiltonian is constructed in the site (diabatic) basis. We also diagonalise it to identify the energy eigenstates, which is useful for interpreting the long-time dynamics.

The simulation starts with the excitation fully localised on site 0 (the higher-energy diabatic state),

$$ \rho_S(0) = |0\rangle\langle 0|. $$

The propagation runs for 1000 fs with a time step of 1 fs, and the HEOM hierarchy is truncated at depth dim = 30.

H = np.array([[1500/2, 600/2], [600/2, -1500/2]], dtype=np.complex128)

# Diagonalization
evals, U = np.linalg.eigh(H)
id_max = np.argmax(evals)

end_time = 1000.0 #fs
dt = 1
wfn = np.array([1.0, 0.0], dtype=np.complex128)

Propagation: Train vs Tree Tensor Networks

Both propagations use identical physical parameters — same Hamiltonian, same bath, same initial state, same hierarchy depth. The only difference is the internal tensor-network topology used to represent the HEOM auxiliary density matrices.

Train Tensor Network (TT / MPS)

A linear chain of tensors where each node connects only to its nearest neighbours. This is the standard Matrix Product State (MPS) architecture, efficient for systems with short-range entanglement structure. In TENSO this is selected with frame_method='train'.

Tree Tensor Network (TTN)

A hierarchical binary-tree of tensors, where each node can connect to two children and one parent. The branching structure allows TTN to capture longer-range correlations with the same bond dimension. In TENSO this is selected with frame_method='tree2'.

If both topologies are converged, they must produce identical populations — any discrepancy indicates that one or both runs need a larger bond dimension or hierarchy depth. The comparison below serves as a cross-validation benchmark.

for out in outs:
    propagator = spin_boson(
        fname=out,
        init_rdo=np.outer(wfn, wfn.conj()),
        sys_ham=np.array([[1500/2, 600/2], [600/2, -1500/2]], dtype=np.complex128),
        sys_op=np.array([[0.5, 0.0], [0.0, -0.5]], dtype=np.complex128),
        bath_correlation=bath_simulation,
        dim=30,
        end_time=end_time,
        step_time=dt,
        frame_method=out,
    )
    progress_bar = tqdm(propagator, total=ceil(end_time / dt))

    for _t in (progress_bar):
        progress_bar.set_description(f'@{_t:.2f} fs')

Results and Visualization

We plot two panels:

  • (a) Populations — $\rho_{00}(t)$ and $\rho_{11}(t)$ for both tensor-network topologies. Solid lines show the TT (Train) result; dashed lines show the TTN (Tree) result. Agreement between the two confirms convergence.
  • (b) Spectral density — $J(\omega)$ for the combined bath, with an inset zooming into the low-frequency Drude–Lorentz peak.

The data files train.dat.log and tree2.dat.log store the full reduced density matrix at each time step. Populations are read from columns 1 and 4 (0-indexed), which correspond to $\rho_{00}$ and $\rho_{11}$ respectively.

def load_spinboson_pops(fname, convert_to_ps=False):
    arr = np.genfromtxt(fname, dtype=complex, comments="#", skip_header=1)
    t = arr[:,0].real
    if convert_to_ps:
        t *= 1e-3
    pops = np.vstack((arr[:,1].real, arr[:,4].real)).T
    return t, pops

def drude_sd(omega, re_d, width_d):
    J = np.zeros_like(omega)
    for lam, gamma in zip(re_d, width_d):
        J += 2*lam*gamma*omega/(omega**2 + gamma**2)
    return J

def brownian_sd(omega, re_b, freq_b, width_b):
    J = np.zeros_like(omega)
    for lam, w0, gamma in zip(re_b, freq_b, width_b):
        J += 2*lam*w0**2*gamma*omega/((w0**2 - omega**2)**2 + (gamma*omega)**2)
    return J

# load data
convert = (time_units.lower() == "ps")
t_sb, p_sb = load_spinboson_pops(file_sb, convert_to_ps=convert)
t_sb2, p_sb2 = load_spinboson_pops(file_sb2, convert_to_ps=convert)

# build spectral densities
omega = np.linspace(0, 2000, 2000)
J_dl = drude_sd(omega, re_d, width_d)
J_bo = brownian_sd(omega, re_b, freq_b, width_b)
J_tot = J_dl + J_bo

# make figure
fig, (ax1, ax2) = plt.subplots(
    2,1, figsize=(3.4, 3.0), gridspec_kw={"hspace":0.4}

ax1.plot(t_sb2, p_sb2[:,0],'--', label=r"$\rho_{00}$ TTN")
ax1.plot(t_sb2, p_sb2[:,1], '--', label=r"$\rho_{11}$ TTN")
